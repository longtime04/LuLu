# LuLu

[English](README.md) | [正體中文](README_zh-Hant.md)

> 中文版构建说明：这是开源 LuLu（GPL-3.0）的中文版，界面已完整中文化（简体中文），基于上游 LuLu 4.5.7，支持 macOS 10.15 及以上。构建为未签名版：主程序能打开，但断网靠的系统扩展必须用苹果开发者证书签名才能装到真 Mac 上，没有证书签名时断网功能跑不起来；有了开发者证书重新签名后即可正常使用。
